完整流程對照

兩種角色，一條配對路

🎤
Match Maker 推薦人
替好友建立 Pitch，作為媒合橋樑
1
貼上朋友的 IG 網址
公開帳號直接分析貼文、簡介、互動風格。私人帳號可上傳截圖，AI 從畫面萃取資訊。
2
AI 自動生成 3 張投影片
系統根據 IG 資料生成「認識他／他的亮點／他在找誰」三頁草稿，Match Maker 可編輯。
3
回答補充問卷
AI 用對話式提問填補 IG 看不出的事：個性、理想對象、有趣的生活故事。
4
輸入 Email 完成註冊
帳號建立完成。Pitch 草稿送交朋友審核，未核准前對任何人不可見。
5
收到配對通知，決定是否介紹
有 User 右滑表示興趣後，Match Maker 收到通知。由 Match Maker 決定是否發起三方介紹對話。
👤
User 瀏覽者
探索 Pitch，右滑表達興趣
1
瀏覽探索頁的個人檔案
每張卡片顯示 AI 生成的 3 頁投影片、推薦人是誰、雙方共同好友數量。
2
右滑或按愛心表達興趣
不是直接配對——而是通知對方的 Match Maker，由 Match Maker 判斷是否適合介紹。
3
等待 Match Maker 回應
Match Maker 可接受或婉拒介紹。若接受，Match Maker 會在群組對話中替雙方暖場破冰。
4
配對成功，開始私訊
Match Maker 功成身退，User 與被推薦者進入一對一私訊，對話視窗顯示「由誰介紹」。
5
繼續探索或分享 App
配對成功的 User 可邀請自己的朋友加入成為新的 Match Maker，形成口碑推薦飛輪。

核心功能設計

六大差異化特色

✦
IG 一鍵生成 Pitch
貼上 IG 網址或上傳截圖，AI 自動分析並生成 3 張投影片草稿。私人帳號也支援截圖匯入。
🎤
對話式問卷補充
AI 透過自然對話問出 IG 看不到的事——性格、理想對象、朋友眼中的他，讓 Pitch 更立體。
❤️
右滑 → Match Maker 通知
User 的右滑不是直接配對，而是通知 Match Maker。Match Maker 才是撮合的關鍵一棒。
🔗
共同好友社交背書
每張卡片顯示雙方共同好友數，讓陌生感降低。Match Maker 本身就是最強的信任保證。
💬
三方介紹暖場
配對成功後 Match Maker 在群組對話中先暖場再退出，每個對話都留有「由誰介紹」的標記。
🎁
Match Maker 信譽系統
配對成功次數越多，Match Maker 的徽章等級越高，推薦的 Pitch 曝光優先度也越高。
